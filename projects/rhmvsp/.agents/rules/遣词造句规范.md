# 格式约束规范

## 连字符与破折号

- 允许：连字符（-）用于构造复合词（如 time-dependent、multi-modal、Branch-and-Price、mixed-integer）
- 禁止：短破折号（-- 或 –）和长破折号（--- 或 —）

## 标点符号

- 禁止：分号（完全省略或用逗号、句号代替）
- 禁止：引号（完全避免使用）

## 禁用学术套话（中文）

严格避免以下词汇：

- 弥合
- 闭环
- 范式
- 跃迁
- 内生化
- 劣化

## 禁用学术套话（英文）

严格避免以下表达：

- bridge the gap（改用 address this gap 或类似表达）
- closed loop
- paradigm
- leap
- internalize / internalization（改用 incorporate、embed 或 model）
- deteriorate / deterioration（改用 increase 或 degradation）

## 语言风格要求

### 极端克制与客观

- 学术论文必须极其克制、客观，避免自吹自擂（boastful）
- 文字需干练（Dry）、硬核、充满事实密度
- 严禁为了凑字数、装门面、拖慢节奏而过度堆砌词汇，只保留支撑核心逻辑的词

### 词汇清洗规范

- **删除主观定性与夸张词**：禁止使用 catastrophic、aggressive、rigid、careful、hyper-connected、more sophisticated 等主观评价词
- **将评价词改为客观事实词**：例如将 economical corridors 改为更直白的 low-cost corridors
- **删除啰嗦的程度副词**：剔除 precisely、directly、exact、effectively、unchecked、inherently、fundamentally、strictly、significantly 等无实际意义、可有可无的修饰词
- **屠宰无意义的形容词**：彻底清除 empirical, distinct, heavy, superior, complete, complex, scalable, highly 等纯粹为了拖慢节奏的学术形容词
- **清洗非逻辑副词**：剔除完全不起“起承转合”作用的虚词（如 decisively, consistently, proactively），只留下 Furthermore, Finally, Consequently 这类真正引领逻辑走向的硬核连词
- **保留技术定语**：仅允许保留不可省略的技术定语，如 reliable、time-dependent、maximum、diminishing、topological 等

### 平实直接的语言

- 中英文文本均需使用平实、直接、简单的语言，不允许使用任何修辞手法
- 长短句交错使用但是必须合理

### 语言分离

- .docx 文件仅使用中文
- .tex 文件仅使用英文
